# Pathly pilot questionnaire

This is a small usability/feasibility pilot, not a learning-outcome study.
Please use a 1--5 scale: 1 = strongly disagree, 5 = strongly agree.

1. The learning plan was clearly organised.
2. The learning order made sense to me.
3. The plan reflected my existing background.
4. The generated learning unit was easy to understand.
5. I would consider using this system for self-study.

Open questions:

1. What was the most helpful part?
2. What most needs improvement?

Record only an anonymised participant code, the goal used, and optional free-text feedback. Obtain the appropriate consent before collecting responses.
